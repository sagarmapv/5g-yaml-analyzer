How this tool helps

Two complementary views on the same 5G procedure — narrative context and signaling mechanics.

Knowledge stream

Master stories stitch Stage-2 procedures (TS 23.502) with Stage-3 service definitions (TS 29.5xx). Each step links to the spec clause that motivates it, with short previews so you can read without opening a dozen PDFs at once.

  • PDU Session Establishment with SM Policy — anchor TS 29.512
  • Inline spec previews for TS referenced in the journey
  • 3-layer chain: procedure → NF role → SBI operation

Technical stream

The ladder, topology, and message views answer “what is sent, between whom, and on which interface?” Steps come from a curated flow graph, not hand-drawn diagrams.

  • Signaling ladder — filter by NF, expand JSON inline
  • NF topology — graph of SBI relationships from the YAML Bank
  • Message envelopes — representative request headers and bodies
  • NF catalog — tiers, interfaces, and procedure roles

Run the full platform locally

GitHub Pages serves a baked snapshot. For live corpus search, spec detail, and PDF refresh:

git clone https://github.com/sagarmapv/5g-yaml-analyzer.git
cd 5g-yaml-analyzer
pip install -r requirements.txt
python scripts/build.py
python -m backend.app
# open http://127.0.0.1:5000
